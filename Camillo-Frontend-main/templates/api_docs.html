Developer API Reference

Integrate Camillo-v2's malicious URL detection engine directly into your own applications.

POST /api/analyze-url

Analyzes a given URL through heuristic rules and a TensorFlow deep learning model to predict whether it is a phishing or malicious link.

Request Headers

Header Value Description
Content-Type application/json Required. Set to JSON content.

Request Body

The URL to analyze must be URL-safe Base64 encoded to prevent parsing issues with special characters in the payload.

Field Type Required Description
url string Yes The URL-safe Base64 encoded URL to analyze (e.g., aHR0cHM6Ly9nb29nbGUuY29t).

Request Example (Python)

import requests
import base64

api_url = "http://localhost:6969/api/analyze-url"
target_url = "https://google.com"

# Encode URL to URL-safe Base64
encoded_url = base64.urlsafe_b64encode(target_url.encode('utf-8')).decode('utf-8')

payload = {
    "url": encoded_url
}

response = requests.post(api_url, json=payload)
data = response.json()
print("Phishing Verdict:", data.get("final_verdict"))
print("Trust Score:", data.get("trust_score"))
print("Model Score:", data.get("model_score"))

Request Example (cURL)

curl -X POST http://localhost:6969/api/analyze-url \
  -H "Content-Type: application/json" \
  -d '{"url": "aHR0cHM6Ly9nb29nbGUuY29t"}'

JSON Response Schema

Key Type Description
status string SUCCESS or ERROR.
url string The analyzed URL string.
trust_score integer A score from 0–100 calculated using traditional heuristic analysis (higher = safer).
model_score integer Suspicion score from 0–100 predicted by the TensorFlow neural network (higher = more suspicious).
final_verdict boolean true if flagged as phishing/malicious, otherwise false.
google_verified string Google Safe Browsing verification status (yes, no, error).
breakdown array A detailed breakdown list containing heuristic rule failures with severity tags.
